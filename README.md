## 🧠 How a Neural Network Learns (Quick Visual)

```mermaid
flowchart LR
    X[📥 Input] --> F[Forward Pass]
    F --> L[📉 Loss]
    L --> B[Backpropagation]
    B --> U[⚙️ Update Weights<br/>Adam / SGD]
    U --> F
```

```mermaid
flowchart LR
    Q[❓ User Query] --> E[Embed]
    E --> V[(Vector DB)]
    V --> R[Retrieve + Re-rank]
    R --> P[Prompt + Context]
    P --> LLM[🤖 LLM]
    LLM --> A[✅ Answer]
```
